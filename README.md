# Hack The Box — Tools & Resources

A personal collection of tools, scripts, exploits, commands, and resources used during my **Hack The Box (HTB)** machine-solving sessions.

This repository serves as a reference for tools and techniques explored throughout hands-on penetration testing labs, including enumeration, exploitation, privilege escalation, vulnerability research, and post-exploitation.

## Contents

- **Tools & Scripts:** Custom scripts, utilities, and tools used during machine investigations.
- **Exploitation:** Exploit code and proof-of-concept implementations explored in lab environments.
- **Privilege Escalation:** Resources and techniques for identifying and exploiting privilege escalation paths.
- **Enumeration:** Commands, scripts, and utilities used to discover services, information, and potential attack vectors.
- **Research & References:** Notes, PoCs, and supporting resources collected during technical research.

## Disclaimer

All materials in this repository are intended for **educational purposes** and authorized lab environments, such as Hack The Box. They should only be used on systems for which permission has been granted.
